# 课程会话改为"第一个学生加入时才建"

课程会话（`conversations` + `course_conversations`）原来在 `courses` 表插入时（管理页新增/修改单门课、批量物化目录）由触发器立即创建，不管这门课有没有学生；一所学校几千门课批量物化后就是几千个空会话，这个代价在目录整合上线时就已经记录（见[目录整合交接](../handoffs/course-catalog-integration.md)「一个已知代价」）。现在改为会话只在第一名学生加入该课程（`course_members` 该门课的第一行）时惰性创建，之后加入的学生直接复用同一个会话；建课与物化目录本身不再产生任何会话数据，避免为长期无人选的课程持续积累空会话。
