# Domain Docs

项目保持单一领域上下文：根目录 `CONTEXT.md` 定义术语，`docs/adr/` 记录决策。

- 开始分析或实施前，阅读 `CONTEXT.md`；已经读过且未变化时复用本次上下文。
- 按 [任务与代码索引](../README.md)选择相关 ADR 和模块资料，不默认通读全部 handoff / runbook。
- 使用统一术语；方案与 ADR 冲突时必须明确指出，不能静默覆盖。
- [STATUS.md](../STATUS.md)维护当前进度，handoff 只保留当时背景与证据；旧状态不可当作当前实测。
- 没有相关文档时继续工作，不提前创建空文档。
