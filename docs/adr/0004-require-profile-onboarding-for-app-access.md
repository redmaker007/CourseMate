# 使用主应用前必须完成 Profile onboarding

邮箱验证后仍先独立创建成员账号，保持认证身份与公开资料的存储边界；但成员必须创建含显示名称的 Profile，才能使用 CourseMate 主应用。这个决定以一次不可跳过的首次登录步骤换取所有课程和社交界面都可依赖的公开名称；头像、专业和毕业年份等其余资料仍为可选项。

本决定只取代 ADR-0001 中“Profile 可以整体缺失且仍可使用主应用”的部分；`member_accounts` 与 `profiles` 分离、学校归属只存于成员账号的边界继续有效。已有不符合新显示名称限制的资料不得被静默截断，必须保留并引导成员修正后才视为完成 onboarding。
