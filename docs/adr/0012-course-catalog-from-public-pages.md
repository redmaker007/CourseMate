# 课程目录可以来自学校无需登录的公开页面

取代 [ADR-0002](0002-do-not-reverse-engineer-university-course-search.md)。

课程目录（课号、课名、学期）可以取自学校**无需登录、没有自动化拦截**的公开课程页面，不再要求必须走 CAOS、ITS API Directory 这类授权渠道。**绕过访问控制仍然不允许**：需要登录或 SSO 的页面、对程序访问返回 403 或验证码的站点、需要伪装成浏览器才能拿到的接口，一律不用。

## 为什么改

2026-11-21 主开发者决定导入两份队友整理的课表：

- **MSU**（8,326 门）：取自 `reg.msu.edu/Courses/Search.aspx` 公开课程查询页，另有 2 门取自学校公开的课程审批文件。
- **UMich 安娜堡**（21,196 门）：15,430 门取自 Wolverine Access 课程目录（`csprod.dsc.umich.edu/services/coursecatalog`），5,759 门取自 LSA 公开课程公告（`webapps.lsa.umich.edu/CrsMaint/Public/...`），7 门取自院系公开课程列表。

这两份都不是 ADR-0002 指定的授权渠道。ADR-0002 的核心顾虑是"绕过访问控制"，而不是"读取公开页面"；冷启动阶段三所学校都需要完整课表，等授权的周期（UMich 还需要教职工背书）跟不上推广节奏。

## 边界

- 只用公开、无需登录的页面。拿不到就不拿，不伪装浏览器、不绕过 403、不用学生账号登录后抓取。
- 只存课号、学科、编号、课名、学期和来源，不存任何个人信息。
- CSV 里的 `source_url` 保留来源，方便事后核对。
- **当时未核实的部分**：从两份 CSV 本身无法判断采集时是否触发过访问控制。Wolverine Access 的那 15,430 门尤其需要采集人确认是公开可访问的。如果发现某个来源需要登录或有自动化拦截，删掉该来源的数据并改走授权渠道。

## 代价

- 学校的服务条款可能限制自动化访问，即便页面公开。推广完全依赖校园渠道，被学校标记仍是最坏结果；有异议时应立即停止并删除对应数据。
- 授权渠道（CAOS、ITS API Directory）仍然更稳，数据更全（学分、先修、简介），拿到授权后应替换。
